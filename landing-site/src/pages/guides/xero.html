Exporting from Xero

One list of payments, exported and uploaded as it is.

Before you begin

What you need

A Xero login that can run and export reports.

A Reclaim account, to upload the file.

Your screen may differ

Menus and report names change between plans and over time. If yours don’t match, look for any report that lists the payments you made, or ask us.

01

Run a payments report

In Xero’s reports, open one that lists the payments you made to suppliers, with a row for each payment. Set the period you want checked and run it.

You want the supplier’s name, the date the money left, the amount, and the supplier’s invoice number if the report can show it. A list of unpaid bills isn’t enough: Reclaim checks what was paid.

02

Export it

Export the report to Excel rather than PDF, which loses the columns. You can upload the Excel file as it is.
