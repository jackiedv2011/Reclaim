Exporting from NetSuite

One list of payments, exported and uploaded as it is.

Before you begin

What you need

A NetSuite role with the Export Lists and Perform Search permissions. Without them, the export button doesn’t appear.

A Reclaim account, to upload the file.

Your screen may differ

Menus and report names change between plans and over time. If yours don’t match, look for any report that lists the payments you made, or ask us.

01

Build a payments search

Go to Lists → Search → Saved Searches → New and create a transaction search for bill payments over the period you want checked.

In the results, include the vendor, the payment date, the amount, and the vendor’s invoice number for the bill each payment was applied to.

02

Export it

Run the search and choose Export - CSV on the results page. Adding the internal ID as a column makes it easier to find a record again later.

# in NetSuite
Lists → Search → Saved Searches → New
results page → Export - CSV
