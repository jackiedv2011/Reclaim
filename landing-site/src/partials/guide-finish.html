03

Upload the file

Log in to Reclaim, click Upload a ledger and drop the file in. It can be up to 50 MB. If a workbook has more than one sheet of rows, Reclaim asks which one to read.

Files it can’t read

Old .xls files, workbooks with a password, and Apple Numbers files. Save those as .xlsx or CSV first. A PDF won’t work either.

04

Match the columns

You’ll only see this step if Reclaim isn’t sure. It shows the first rows of your file, with a suggestion for each column it thinks it knows. Check every suggestion, fill in anything it left empty, then click Continue. Your file isn’t changed.

Check the invoice number twice

Some reports put a check or payment number in the number column. Reclaim compares the number printed on the vendor’s invoice. If your column is a payment number instead, choose Not in this file: matched by mistake, it can hide a bill that was paid twice.

It may also ask:

Dates

Which way round they are, if 03/04/2026 could be March 4 or April 3 and nothing else in the file settles it.

Amounts

Whether negative amounts are payments. Many reports show money going out as a negative. Reclaim treats a negative as a refund or credit unless you tell it to flip the sign.

05

Check it, then run the audit

Before any check runs, Reclaim shows how many payments and vendors it read, the dates they cover, how it read the file, and any rows it skipped. If the numbers don’t look right for the period, choose Check the column matches and go back. Otherwise, run the audit.

One company at a time

If you keep more than one set of books, upload each one separately. Mixing them can make ordinary payments look like duplicates. Keep the original export too, so you can trace a result back to it.

Troubleshooting

Reclaim can’t find a vendor, date or amount

The file may be a vendor list or a list of unpaid bills, which don’t say what was paid. You need a report with a row for each payment. If yours is one, check that each field in step 4 points at the right column, and that Headings are on row shows the right row. You can also compare it with the sample CSV.

The vendor’s name is only written once

Reports grouped by vendor often put the name on a line above its payments. Tick Each vendor’s name is written once, above its payments, if it isn’t ticked already, and Reclaim carries the name down.

Some rows were skipped

A row is skipped when it has no vendor, no date Reclaim can read, or no amount. Title and total lines are meant to be skipped. Before you add anything, Reclaim says how many rows it will skip and shows the first few with the reason.

Can I upload my bills, vendor list or credits too?

Not as separate files. Reclaim checks payments. If your bills file has invoice dates, amounts or terms, copy those columns next to the matching payments and more checks will run.

How far back should I go?

Two years is a sensible first pass. The file can be up to 50 MB. If yours is larger, split it by date and add each part to the same audit.
